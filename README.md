# SQL Data Analysis - E-Commerce Dataset (Project 3)

## 📌 Project Overview
This project focuses on querying relational logic using PostgreSQL to extract actionable business insights from an e-commerce sales dataset consisting of 1,200 transactions.

## 🛠️ Tools & Technologies Used
- **Database Engine:** PostgreSQL 18
- **GUI Tool:** pgAdmin 4
- **Language:** SQL (ANSI Standard)

## 📊 Key Data Insights & Aggregations
- **Total Revenue Generated:** $1,264,761.96
- **Total Orders Processed:** 1,200 orders
- **Average Order Value (AOV):** $1,053.97
- **Top Product Categories by Revenue:** 
  - Chairs ($195,620.11 | 15.47%)
  - Printers ($195,612.61 | 15.47%)
  - Laptops ($192,126.56 | 15.19%)
- **Top Payment Methods:** Credit Card ($263,847.63) & Online ($262,442.94)

## 🔍 SQL Concepts Applied
- **Data Inspection:** `SELECT`, `LIMIT`
- **Filtering:** `WHERE`
- **Categorical Bucketing & Aggregations:** `GROUP BY`, `COUNT()`, `SUM()`, `AVG()`
- **Output Sorting:** `ORDER BY`
- **Group Level Filtering:** `HAVING`
- **Advanced Insights:** Revenue Percentage Share per Product
